# Lifestyle & Health Assessment (Frontend Demo)

A responsive web-based lifestyle and health assessment tool built as a **frontend-focused project**.  
The application simulates AI-generated health insights based on user inputs across nutrition, activity, sleep, and stress.

This project was created to demonstrate **UI design, form handling, DOM manipulation, and overall frontend structure**.

---

## 🔗 Live Demo

👉 **Live Site:**  
[Click to view](https://sankeerthini.github.io/lifestylehealth-assessment/)

---

## ✨ Features

- Multi-section health & lifestyle assessment form
- Clean, modern UI with responsive layout
- Simulated AI-generated health perspectives
- Persona-based summary with visual cards
- Interactive star rating for insights
- One-click PDF download using browser print
- Clear AI mock disclaimer for transparency

---

## 🧠 About the AI Disclaimer

This project uses **mocked AI logic** and does **not connect to any real AI or backend services**.

All AI-related outputs are intentionally simulated.

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- No frameworks or backend
